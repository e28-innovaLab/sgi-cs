# SIGES

**Sistema de Gestión Institucional Inteligente para el Centro de Simulación.**

## Frontend

Prototipo de la interfaz web de SIGES desarrollado con React y Vite.

### Funcionalidades implementadas

- Inicio de sesión.
- Panel principal de gestión.
- Visualización de espacios.
- Gestión de reservas.
- Gestión de recursos y equipos.
- Navegación entre módulos.

### Tecnologías

- React
- JavaScript
- HTML
- CSS
- Vite

## Instalación y ejecución

1. Clonar el repositorio.
2. Instalar las dependencias:

   ```bash
   npm install
   ```

3. Iniciar el servidor de desarrollo:

   ```bash
   npm run dev
   ```

Este proyecto forma parte del trabajo colaborativo de InnovaLab.
